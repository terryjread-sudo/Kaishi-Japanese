# Sensei’s Desk media

The mode uses a generated desk illustration and paper texture as local UI art.

The audio assets are CC0 releases from OpenGameArt:

- [Spy Loop](https://opengameart.org/content/spy-loop) by Juhani Junkala — desk shift music.
- [Sunset Walk](https://opengameart.org/content/sunset-walk-ambient-quiet-sweet-loop) by Juhani Junkala — calm alternate music source.
- [10 Book Page Flips](https://opengameart.org/content/10-book-page-flips) — paper review sound.
- [Mechanical Sounds](https://opengameart.org/content/mechanical-sounds) by qubodup — typewriter stamp sound.
- [Basic Sound Effects](https://opengameart.org/content/basic-sound-effects) by Juhani Junkala — completion cue.

All external audio was downloaded from the original OpenGameArt files and is included locally so the game remains usable offline.
