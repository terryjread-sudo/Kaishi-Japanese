# Animated Kanji stroke-order assets

This folder contains the 105 SVG stroke-order animations used by Kaishi Quest's curated Kanji component lessons.

Source: [KanjiVG](https://kanjivg.tagaini.net/) by Ulrich Apel.

License: [Creative Commons Attribution-ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The original attribution and license notice are retained in every SVG file.

The supplied Anki deck was inspected to identify the compatible SVG animation format. Only the small component-lesson subset is included, rather than the deck's full 2,438-character media library.
