KAISHI QUEST v3.0.0

UPLOAD
1. Extract this ZIP.
2. Open the Kaishi_Quest_v3.0.0_ready folder.
3. Upload everything inside it to the ROOT of your GitHub repository.
4. Keep the memory-scenes folder intact.
5. Allow GitHub to replace files with the same names.
6. Commit as: Release Kaishi Quest v3.0.0

WHAT CHANGED
- Interleaved lessons with 2–4 active words.
- Four Picture Match modes.
- Easy, Normal and Expert picture difficulty.
- 50 new cartoon/anime-style scene cards.
- Updated memory-scene manifest and service-worker cache.

NOTE
The manifest deliberately references the original 50 scenes plus the 50 new v3 scenes.
Older abstract v2.2 images are no longer used by the app when they are absent from memory-scenes.json.
