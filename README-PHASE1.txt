# Kaishi Quest v4.1.0 — Visual Mnemonics Phase 1

Upload the files in this ZIP to the root of the GitHub repository, replacing `index.html`.

New files:
- `visual-mnemonics.json`
- `vms.js`
- `vms.css`
- `mnemonic-studio.html`
- `mnemonic-studio.js`

This release adds:
- enhanced data for the first 20 cards;
- progressive Picture → Kanji → Reading → Story reveal;
- optional kanji overlay;
- VMS settings stored locally;
- a basic Mnemonic Studio with preview, local drafts and JSON export;
- fallback to the existing Memory Scene whenever no enhanced card exists.

The existing `app.js`, vocabulary data and image files remain unchanged.
